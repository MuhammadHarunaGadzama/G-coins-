# 🪙 G-Coins

G-Coins is a web-based digital mining and rewards platform where users can mine G-Coins, invite friends, and request withdrawals.

## ✨ Features

- ⛏ 12-Hour Mining
- 💰 Wallet
- 👥 Referral System
- 📜 Transaction History
- 💸 Withdrawals
- 🎁 Watch & Earn
- 📱 Mobile Responsive
- 🔒 Secure User Accounts

## 📂 Pages

- index.html
- signup.html
- home.html
- wallet.html
- profile.html
- referral.html
- watch-earn.html
- withdraw.html
- history.html

## 💵 Withdrawal Rules

- Minimum Withdrawal: **100 G-Coins**
- Invite at least **5 friends**
- Withdrawal requests are reviewed before approval.
- Users will receive a notification after approval.

## 📢 Advertisement

This project is designed to support Adsterra advertisements.

Ads can be placed on:

- Home
- Watch & Earn
- Wallet
- History
